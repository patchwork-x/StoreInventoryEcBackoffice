# 店舗在庫連携型ECバックオフィスシステム

## 概要

全国に複数店舗を展開するリユース・小売企業を想定した、EC注文・店舗在庫・社内問い合わせを一元管理する社内業務システムです。

EC注文、店舗在庫、商品マスタ、問い合わせ・改修依頼、操作ログを管理し、ECシステム部門における運用保守や改修対応を想定して作成しました。

## 作成目的

このポートフォリオは、ECシステム開発課の業務を想定して作成しています。

特に以下を意識しています。

- EC注文と店舗在庫の連携
- 商品マスタ管理
- 社内問い合わせ・改修依頼管理
- 運用保守を意識した操作ログ
- 検索・絞り込みによる業務効率化
- SQLを意識したデータ設計

## DBについて

ローカル環境での再現性を高めるため、デモ用DBとしてSQLiteを使用しています。

ただし、DB設計はSQL Server等のRDBMSを想定しており、Entity Framework CoreのProviderと接続文字列を変更することで、SQL Server環境にも切り替え可能な構成です。

## 設計上の工夫

### EC注文と店舗在庫の分離

注文情報と在庫情報を分けることで、EC注文処理と店舗在庫管理を独立して扱えるようにしました。

### 問い合わせと注文・商品の紐づけ

社内問い合わせや改修依頼を、関連する注文や商品に紐づけられる構成にしました。

これにより、問い合わせ対応時に対象データを確認しやすくしています。

### 操作ログによる調査性向上

商品、注文、問い合わせなどに対する操作履歴を保持することで、運用保守時の調査性を高めています。

### 検索・絞り込みの重視

実務では一覧画面から対象データを探す場面が多いため、各画面に検索・絞り込み機能を実装しました。

## 起動手順

1. Webプロジェクトへ移動

cd StoreInventoryEcBackoffice.Web

2. パッケージ復元

dotnet restore

3. DB作成

dotnet ef database update

4. アプリ起動

dotnet run

5. ブラウザでアクセス

https://localhost:5219
